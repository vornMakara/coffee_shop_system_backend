☕ Coffee Shop POS - Backend Stack

An overview of the libraries, tools, and dependencies powering the Laravel API.

Core Framework & Environment

  • Core Laravel Framework The primary PHP framework handling routing, ORM (Eloquent), and business logic.
    ^9.19
  • Runtime PHP The server-side scripting language required to run the backend.
    ^8.0.2

Authentication & Security

  • Auth php-open-source-saver/jwt-auth Handles JSON Web Token (JWT) generation and validation for secure, stateless API authentication. Replaces Laravel Sanctum.
    Latest

Production Libraries

  • HTTP Guzzle HTTP A powerful PHP HTTP client that makes it easy to send outbound requests to third-party services (e.g., payment gateways).
    ^7.2
  • CLI Laravel Tinker An interactive REPL command-line interface for interacting with the Laravel application and database.
    ^2.7

Development & Testing (DevOnly)

  • Data FakerPHP Generates fake realistic data (names, prices, coffee names) to populate the database for testing.
    ^1.9.1
  • Docker Laravel Sail A light-weight command-line interface for interacting with Laravel's default Docker development environment.
    ^1.0.1
  • Testing PHPUnit The standard testing framework for PHP to run unit and feature tests.
    ^9.5.10
  • Testing Mockery A simple yet flexible PHP mock object framework for use in unit testing.
    ^1.4.4
  • Code Style Laravel Pint An opinionated PHP code style fixer to keep the codebase clean and consistent.
    ^1.0
  • Debugging Spatie Ignition & Collision Provides beautiful, readable error pages and console error output when something breaks during development.
    Various
