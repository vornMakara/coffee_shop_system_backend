🚀 Backend MVP 1 Roadmap

Core POS System - Database, Auth, and APIs

Phase 1: Foundation

You cannot build APIs without the database and models being ready.
  • Config
    Task 1: Environment & Database
    • Set up .env file with MySQL credentials.
    • Ensure database connection is active.
  • Database
    Task 2: Create Core Migrations
    • Create users, roles, branches, and customers tables.
    • Create brands, units, categories, and products tables.
    • Create modifier_groups, modifier_options, and product_modifier_mapping tables.
    • Create tables and table_categories tables.
    • Create orders and order_items tables.
    • Create sales, sale_payments, payment_methods, shifts, and shift_cash_movements.
  • Eloquent
    Task 3: Models & Relationships
    • Define hasMany and belongsTo on all newly created models.
    • Setup fillable properties for mass assignment security.
  • Testing Data
    Task 4: Database Seeders
    • Write a DatabaseSeeder to generate 1 Admin, 1 Cashier.
    • Generate 3 Categories and 10 dummy Coffee Products.

Phase 2: Security & Auth

You cannot process orders if you don't know who the cashier is.
  • JWT
    Task 5: Configure Authentication
    • Install and configure php-open-source-saver/jwt-auth.
    • Implement JWTSubject on the User model.
  • API Endpoints
    Task 6: Auth Endpoints
    • POST /api/v1/auth/login (Returns JWT Token).
    • POST /api/v1/auth/logout (Invalidates Token).
    • GET /api/v1/auth/me (Returns logged-in user profile).

Phase 3: Core API (Read Operations)

The Nuxt.js frontend needs these to display the menus and POS screen.
  • API Endpoints
    Task 7: Catalog & Menu APIs
    • GET /api/v1/categories
    • GET /api/v1/products (Filterable by category).
    • GET /api/v1/products/{id} (Includes product modifiers).
  • POS Data
    Task 7.5: POS Core Data APIs
    • GET /api/v1/shifts/current and POST /api/v1/shifts/open
    • GET /api/v1/tables (List tables with availability)
    • GET /api/v1/customers (Search by phone or name)

Phase 4: Business Logic (Write Operations)

The most complex part of MVP 1: Processing a sale.
  • Critical Logic
    Task 8: Create Order API
    • POST /api/v1/orders
    • Calculate total price, save main Order, and loop through cart array to save OrderItems (and modifiers).
  • Transactions
    Task 9: Process Payment API
    • POST /api/v1/orders/{id}/pay
    • Mark order as Paid, record in sales and sale_payments table, update shift_cash_movements.
  • Order Tracking
    Task 10: Order Status and Queue Tracking
    • GET /api/v1/orders/{identifier} (Customer Tracking)
    • PATCH /api/v1/orders/{id}/status (POS Staff Update)
  • Order Management
    Task 11: List and Delete Orders
    • GET /api/v1/orders (List orders with optional status filter)
    • DELETE /api/v1/orders/{id} (Soft-delete/void an order)

Phase 5: Role-Based Access Control (RBAC)

Dynamic permissions to secure endpoints before moving to KDS.
  • Architecture
    Task 12: Dynamic Permissions Config & Command
    • Create config/permissions.php as master dictionary.
    • Implement php artisan rbac:sync to sync config to database.
  • Database
    Task 13: RBAC Schema & Seeder
    • Migrate permissions, role_permissions, user_permissions.
    • Create RolesAndPermissionsSeeder to seed default roles and assign permissions.
  • Security
    Task 14: API Protection & Admin Routes
    • Create CheckPermission middleware and protect POS routes.
    • Implement GET /api/v1/permissions, GET /api/v1/roles, POST /api/v1/roles, PUT /api/v1/roles/{id}/permissions.

MVP 1 - Phase 6: Admin Data Management (CRUD)

Building backend API endpoints for the Admin Dashboard to manage resources.
  • Auth & POS
    Task 15: Users, Branches, Tables, & Customers API
    • CRUD endpoints for users, branches, tables, and customers.
    • Implemented SoftDeletes to preserve historical data.
  • Catalog
    Task 16: Menu & Catalog Management API
    • CRUD endpoints for categories, products, and modifiers.
    • Implemented POST /api/v1/admin/products/{id}/modifiers to sync product_modifier_mapping.
