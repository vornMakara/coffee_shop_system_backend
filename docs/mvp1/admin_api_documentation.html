Users Management

GET /api/v1/admin/users

List Users

Retrieve a paginated list of users. Requires admin.users permission.

Example Response (200 OK)
{
    "status": "success",
    "message": "Users retrieved successfully.",
    "data": {
        "current_page": 1,
        "data": [
            {
                "name": "John Doe",
                "email": "john@example.com",
                "role": "Manager",
                "is_active": true,
                "id": "uuid",
                "created_at": "2023-10-01T12:00:00Z",
                "updated_at": "2023-10-01T12:00:00Z"
            }
        ],
        "total": 1
    }
}

Admin RBAC Routes

Note: All of the following routes require the admin.roles permission.

GET /api/v1/permissions

List All Permissions

Get a master list of all permissions, grouped by category (e.g. POS, Admin, KDS).

Example Response (200 OK)
{
  "status": "success",
  "data": {
    "POS": [
      {
        "id": "uuid",
        "name": "pos.access",
        "description": "Access the POS register and create orders"
      }
    ],
    "Admin": [
      {
        "id": "uuid",
        "name": "admin.roles",
        "description": "Manage roles and permissions"
      }
    ]
  }
}
GET /api/v1/roles

List Roles

Get all roles along with their assigned permissions.

Example Response (200 OK)
{
  "status": "success",
  "data": [
    {
      "id": "uuid",
      "name": "Manager",
      "permissions": [
        {
          "id": "uuid",
          "name": "pos.void"
        }
      ]
    }
  ]
}
POST /api/v1/roles

Create Role

Create a new custom role and optionally assign permissions to it.

Example Request Body
{
    "name": "Weekend Manager",
    "display_name": "Weekend Manager",
    "description": "Can manage staff during weekends",
    "permissions": ["uuid-of-permission1", "uuid-of-permission2"]
}
Example Response (201 Created)
{
  "status": "success",
  "message": "Role created successfully",
  "data": {
    "id": "uuid",
    "name": "Weekend Manager"
  }
}
PUT /api/v1/roles/{id}/permissions

Update Role Permissions

Update the assigned permissions for a specific role.

Example Request Body
{
    "permissions": ["uuid-of-permission1", "uuid-of-permission2"]
}
Example Response (200 OK)
{
  "status": "success",
  "message": "Role permissions updated successfully"
}
