Authentication

POST /api/v1/auth/login

Login Cashier

Authenticates a cashier using their credentials and returns a JWT token.

ParameterDescription
email Required
string		Cashier email.
password Required
string		Cashier password.
Example Request Body
{
  "email": "cashier@coffeeshop.com",
  "password": "secret123"
}
Example Response
{
  "status": "success",
  "data": {
    "access_token": "eyJhbGciOi...",
    "token_type": "bearer",
    "expires_in": 3600
  }
}
GET /api/v1/auth/me

Get Current User

Retrieves the profile of the currently authenticated cashier.

Example Response
{
  "status": "success",
  "data": {
    "id": "uuid",
    "first_name": "Sarah",
    "last_name": "Connor",
    "role": {"name": "Cashier"}
  }
}
POST /api/v1/auth/logout

Logout

Invalidates the current JWT token.

Example Response
{
  "status": "success",
  "message": "Successfully logged out"
}

POS Core Data

GET /api/v1/shifts/current

Get Current Shift

Checks if the current cashier has an active shift.

Example Response
{
  "status": "success",
  "data": {
    "id": "uuid",
    "opened_at": "2023-10-01 08:00:00",
    "starting_cash": 150.00
  }
}
POST /api/v1/shifts/open

Open Shift

Opens the register for the cashier with a starting float.

ParameterDescription
opening_cash Required
number		Starting USD cash in drawer.
opening_cash_khr Required
number		Starting KHR cash in drawer.
Example Request Body
{
  "opening_cash": 150.00,
  "opening_cash_khr": 400000.00
}
Example Response
{
  "status": "success",
  "message": "Shift opened successfully.",
  "data": {"id": "uuid"}
}
GET /api/v1/tables/categories

List Table Categories

Returns table zones (e.g., Indoor, Outdoor).

Example Response
{
  "status": "success",
  "data": [
    {"id": "uuid", "name": "Indoor"}
  ]
}
GET /api/v1/tables

List Tables

Returns all tables and their statuses.

Query ParamDescription
category
string		Optional filter.
Example Response
{
  "status": "success",
  "data": [
    {"id": "uuid", "table_number": "T1", "status": "available", "category": "Indoor"}
  ]
}
GET /api/v1/customers

Search Customers

Query ParamDescription

Example Response

  ]

Orders & POS

GET /api/v1/orders

List Orders

Retrieve active orders for the current shift.

Example Response
{
  "status": "success",
  "data": [
    {"id": "uuid", "order_number": "ORD-001", "status": "pending", "total": 12.50}
  ]
}
POST /api/v1/orders

Create Order

Create a new order without paying yet.

ParameterDescription
items Required
array		Array of products and quantities.
Example Request Body
{
  "branch_id": "uuid",
  "shift_id": "uuid",
  "customer_id": "uuid",
  "table_id": "uuid",
  "order_type": "dine_in",
  "items": [
    {
      "product_id": "uuid",
      "quantity": 2,
      "selected_modifiers": ["uuid-1", "uuid-2"],
      "notes": "Extra hot, please"
    }
  ]
}
Example Response
{
  "status": "success",
  "data": {"id": "uuid", "order_number": "ORD-002"}
}
POST /api/v1/orders/{id}/pay

Process Payment

Process payment and mark order as Paid.

ParameterDescription
payment_method_id Required
uuid		ID of payment method.
Example Request Body
{
  "payment_method_id": "uuid",
  "amount_tendered": 20.00
}
Example Response
{
  "status": "success",
  "message": "Payment processed successfully."
}
GET /api/v1/orders/{order_number}

Track Order (Public)

Fetch current status using order number.

Example Response
{
  "status": "success",
  "data": {"order_number": "ORD-002", "status": "preparing"}
}
PATCH /api/v1/orders/{id}/status

Update Order Status

Update order progress (pending -> preparing -> ready).

Example Request Body
{
  "status": "ready"
}
Example Response
{
  "status": "success",
  "message": "Status updated."
}
DELETE /api/v1/orders/{id}

Void Order

Cancel or void an active order.

Example Response
{
  "status": "success",
  "message": "Order voided successfully."
}
