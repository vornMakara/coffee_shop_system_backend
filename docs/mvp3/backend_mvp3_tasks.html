🚀 Backend MVP 3 Roadmap

Supply Chain & Procurement

Phase 1: Procurement

Buying goods from suppliers.
  • Directory
    Task 1: Supplier Management API
    • CRUD endpoints for suppliers.
  • Orders
    Task 2: Purchase Orders API
    • POST /api/v1/purchase-orders (Create PO and purchase_order_items).
    • Update PO status (Draft -> Sent).

Phase 2: Receiving & Accounts Payable

Verifying deliveries and tracking payments.
  • Stock In
    Task 3: Goods Receipts API
    • POST /api/v1/goods-receipts (Confirm delivered goods).
    • Automatically trigger inventory_movements (purchase) when receipt is confirmed.
  • Finance
    Task 4: Supplier Payments API
    • Endpoints for recording supplier_payments against a PO.

Phase 3: Multi-Branch Logistics

Distributing goods between branches.
  • Transfers
    Task 5: Stock Transfers API
    • POST /api/v1/stock-transfers (Request stock transfer).
    • Update transfer status (Pending -> In Transit -> Received).
    • Auto-deduct from source and add to destination upon receipt.
