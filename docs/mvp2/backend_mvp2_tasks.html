🚀 Backend MVP 2 Roadmap

Kitchen & Inventory Operations

Phase 1: Kitchen Display System (KDS)

Routing digital tickets to kitchen stations.
  • Setup
    Task 1: KDS Station Management API
    • CRUD endpoints for kds_stations and printers.
    • Map specific products to stations (product_station_mapping).
  • Operations
    Task 2: KDS Order Queue API
    • GET /api/v1/kds/orders (Fetch active orders by station).
    • PATCH /api/v1/kds/orders/{id}/status (Update KDS order status to ready).

Phase 2: Basic Inventory Management

Tracking raw ingredients.
  • Catalog
    Task 3: Ingredients & Units API
    • CRUD endpoints for ingredients.
    • Manage ingredient_stocks per branch.
  • Logic
    Task 4: Recipe Management API
    • Map products to ingredients via recipes table.
    • Map modifier_options to ingredients.

Phase 3: Stock Control

Monitoring and adjusting inventory levels.
  • Transactions
    Task 5: Inventory Movement API
    • Auto-deduct stock on order completion (production movement).
    • Endpoints for manual stock_adjustments and waste_records.
  • Alerts
    Task 6: Stock Alert System
    • GET /api/v1/inventory/low-stock (Filter by low_stock_threshold).
